01 · 环境
需要什么

全是本机的东西，不碰云端。

项目要求
系统Windows 10 / 11，x64
QQQQNT 桌面版，普通安装即可，不用改任何安装文件
Node.js装一个较新的 LTS 版本即可，项目零 npm 依赖，不需要 npm install
ffmpeg（可选）只有群相册上传视频要拿它抽首帧封面；发文本、图片、语音都用不上
02 · 四步
从零到发出第一条消息

每一步都发生在本机。

  1. 正常启动并登录 QQ。界面、聊天照常用，这个客户端你该干嘛干嘛。
  2. 双击 app\启动 FrishLuna.vbs。面板在后台常驻（关窗口不会停），浏览器自动打开 127.0.0.1:5701。想看日志就用 app\前台运行.cmd，关窗口即停。
  3. 输入初始令牌。首次启动会生成一个初始令牌并在控制台打印一次——后台方式看不到输出，所以第一次建议用「前台运行.cmd」跑一遍，把令牌抄下来。
  4. 改掉初始令牌。登录后第一件事：面板设置 → 访问令牌，设置你自己的。设置成功即换盐换哈希，初始令牌立刻作废。
03 · 令牌
访问令牌规则

面板不是公开服务，令牌是唯一门锁。

  • 8 到 64 位，必须同时含字母和数字。可以加 !@#$%^&*()-_+=[]{{}};:,.?/~ 里的符号。不合规的输入前后端都会拦。
  • 只存哈希。项目根 .env 里只有 16 字节盐 + scrypt 哈希，没有明文，也没有能解密回来的副本。
  • 强度提示。设置页有实时强度条：字母+数字为低，大小写+数字为中，再加特殊字符为高。
  • 忘了怎么办。删掉 .env 里 FL_AUTH_* 那几行重启，会重新发一个初始令牌。令牌不可回显，没有找回这回事。
  • 登录态。只存浏览器 sessionStorage，关浏览器即失效。
04 · 验证
怎么确认装好了

三分钟就能验完。

  • 看概览页。连接状态、QQ 进程、消息服务三张卡正常，没有红色报错。
  • 发条测试消息。实验台 → 发消息，挑一个你自己的小群发一句，群里能看到就通了。
  • 验 OneBot。按 OneBot 接入 那页的 curl 示例调一次 get_login_info，能拿到本号 QQ 号就说明协议端也通了。

后台挂着不怕掉：计划任务 FrishLuna Keepalive 每分钟探一次端口，不在就静默拉起，日志在 app\data\keepalive.log。
