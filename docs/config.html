01 · 面板配置
config.json

位置 app/data/config.json，设置页可改。

键说明
port / host面板监听，默认 127.0.0.1:5701；端口被占自动 +1
qqExeQQ 可执行文件路径，需在设置页手动指定
autoInject面板发现 QQ 在跑但没挂载荷时自动注入
blockedGroups禁止发送的群号列表。只拦发送、收消息照常。默认空数组＝不拦任何群，用之前务必填上。
obServerPort / obServerToken / obServerReverseOneBot 服务端：端口（默认 5760）、令牌、反向 WS 地址列表
02 · 令牌存储
.env

项目根目录的 .env 只和令牌有关。

  • FL_AUTH_*：16 字节盐 + scrypt 哈希（N=16384/r=8/p=1，64 字节输出）。没有明文令牌。
  • 删掉这几行重启＝重置令牌，会重新生成初始令牌并打印一次。
  • 这个文件不要提交到任何仓库，.gitignore 已经排除了。
03 · 数据目录
app/data

运行时产生的文件都在这儿。

文件内容
config.json上面的面板配置
panel.port面板真实端口（自动顺延后以它为准），看门狗靠它探测
keepalive.log看门狗日志
frishluna.db本地消息与 ID 映射缓存（SQLite）
04 · 环境变量
可选

没有必须设置的，这些都是可选项。

变量作用
FL_FFMPEG / FL_FFPROBEffmpeg 不在 PATH 里时指定完整路径；只有群相册传视频用得到
FL_QQ_APP / FL_QQ_VER注入器脚本里 QQ 安装路径与版本的覆盖项
